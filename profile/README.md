# Odin Bilişim

Tekirdağ merkezli bir bilişim şirketiyiz. İşletmelere yazılım, web, e-ticaret ve teknik hizmet sunuyoruz;
satış ve kasa yazılımları geliştiriyor, kuruyor ve destekliyoruz.

[odinbilisim.com](https://www.odinbilisim.com) · [info@odinbilisim.com](mailto:info@odinbilisim.com)

## Ürünlerimiz

| Ürün | Ne yapar |
| :--- | :--- |
| **Nova POS** | Market ve perakende için Windows masaüstü satış programı: barkodlu satış, veresiye, kasa, stok ve raporlar. Veriler işletmenin bilgisayarında tutulur, internet kesilse de satış sürer. |
| **OdinPos** | Restoran ve kafeler için adisyon sistemi: masa, mutfak ekranı, paket servis, hesap bölme ve gün sonu raporları. |
| **E-ticaret asistanı** | E-ticaret siteleri için yapay zekâ satış asistanı; gerçek fiyat ve stokla ürün gösterir, paket hazırlar. Şu an kendi sitemizde çalışıyor, pilot kurulumlar planlanıyor. |
| **Web ve e-ticaret** | Kurumsal web siteleri, e-ticaret altyapısı, SEO ve Google Ads yönetimi. |

## Kullandığımız teknolojiler

TypeScript · Next.js · React · Prisma · PostgreSQL · Python · FastAPI · Electron · Docker · Nginx

## Açık kaynak

Bu kuruluştaki açık depolar **deneysel** araçlardır; npm veya PyPI'de yayınlanmadılar ve barındırılan bir
servise bağlanmazlar:

- [`odin-agent-sdk`](https://github.com/Odin-Informatics/odin-agent-sdk) — OpenAI uyumlu sohbet API'leri için küçük bir araç çağıran ajan kütüphanesi (Python). Kendi çalıştırdığınız bir sunucuya (ör. yerel Ollama) bağlanır.
- [`odin-cli`](https://github.com/Odin-Informatics/odin-cli) — yerel geliştirici yardımcı aracı: ortam kontrolü ve `.env` dosyası karşılaştırma. Ağ bağlantısı kurmaz.

Ürünlerimizin kaynak kodu açık değildir.
