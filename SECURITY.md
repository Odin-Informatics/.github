# Güvenlik Politikası

## Desteklenen sürümler

`odin-agent-sdk` ve `odin-cli` deneysel projelerdir. Güvenlik düzeltmeleri yalnızca `main` dalındaki en son
sürüme uygulanır.

## Güvenlik açığı bildirimi

Bu depolarda ya da odinbilisim.com üzerinde bir güvenlik açığı bulduğunuzu düşünüyorsanız:

1. **Herkese açık bir GitHub issue açmayın.**
2. [info@odinbilisim.com](mailto:info@odinbilisim.com) adresine konu satırında "Güvenlik" yazarak e-posta gönderin.
3. Mümkünse şunları ekleyin:
   - açığın kısa tanımı,
   - yeniden üretme adımları,
   - olası etkisi.

Bildirimleri elimizden geldiğince hızlı inceleriz ve size dönüş yaparız. Düzeltme yayımlanmadan açığın
ayrıntılarını paylaşmamanızı rica ederiz.
