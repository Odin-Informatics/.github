# Security Policy & Responsible Disclosure

Odin Informatics places security and zero-trust data protection at the core of all our software engineering practices.

## Supported Versions

| Project / Ecosystem | Version | Supported |
| :--- | :--- | :--- |
| `odin-agent-sdk` | `>= 0.1.0` | :white_check_mark: |
| `odin-cli` | `>= 1.0.0` | :white_check_mark: |
| `odin-pos` Cloud Services | Active Production | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability or potential threat in any Odin Informatics repository or cloud endpoint:

1. **Do not create a public GitHub issue.**
2. Send an encrypted or confidential email directly to our Security Engineering Team at:
   - **Email:** [security@odinbilisim.com](mailto:security@odinbilisim.com)
3. Please include:
   - Detailed description of the vulnerability,
   - Proof of Concept (PoC) or reproduction steps,
   - Potential impact analysis.

---

## Response Timeline

- **Initial Acknowledgement:** Within 24 hours.
- **Triage & Remediation Plan:** Within 72 hours.
- **Patch Release & Advisory:** Coordinated disclosure upon successful patch deployment.
